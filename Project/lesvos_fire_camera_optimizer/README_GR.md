# Βελτιστοποίηση θέσεων καμερών πυρανίχνευσης — QGIS Processing Script

Το script βρίσκει έναν **προσεγγιστικά βέλτιστο** συνδυασμό θέσεων και κατευθύνσεων καμερών. Για κάθε πιθανή θέση:

1. τρέχει ένα viewshed 360° πάνω στο DEM,
2. δοκιμάζει διαφορετικά azimuth,
3. κρατά μόνο τον τομέα του πραγματικού FOV,
4. δίνει μεγαλύτερο βάρος σε δέντρα, θάμνους και χορτολιβαδικές εκτάσεις,
5. μειώνει την ποιότητα ανίχνευσης όσο αυξάνει η απόσταση,
6. επιλέγει διαδοχικά τις κάμερες που προσθέτουν τη μεγαλύτερη νέα κάλυψη.

## Προϋποθέσεις

Χρειάζονται δύο raster:

- DEM σε projected CRS με μονάδες μέτρα, κατά προτίμηση `EPSG:32635`.
- ESA WorldCover ευθυγραμμισμένο ακριβώς με το DEM.

Τα raster πρέπει να έχουν ίδιο:

- CRS,
- extent,
- pixel size,
- width/height,
- grid alignment.

Το script χρησιμοποιεί το εργαλείο `gdal:viewshed`, άρα ο **GDAL provider** πρέπει να είναι ενεργός στο Processing Toolbox.

## Εγκατάσταση στο QGIS

1. Άνοιξε `Processing → Toolbox`.
2. Στο επάνω μέρος του Toolbox άνοιξε το μενού **Scripts**.
3. Επίλεξε **Create New Script from Template**.
4. Σβήσε το περιεχόμενο του editor και αντέγραψε ολόκληρο το αρχείο `lesvos_fire_camera_optimizer.py`.
5. Αποθήκευσέ το στον προτεινόμενο φάκελο `scripts` με κατάληξη `.py`.
6. Στο Processing Toolbox θα εμφανιστεί ομάδα **Πυρανίχνευση** και εργαλείο **Βελτιστοποίηση θέσεων καμερών πυρανίχνευσης**.

Εναλλακτικά, αν γνωρίζεις τον φάκελο του ενεργού QGIS profile, μπορείς να αντιγράψεις απευθείας το `.py` στον υποφάκελο `processing/scripts` και να επανεκκινήσεις το QGIS.

## Πρώτη δοκιμή για τη Λέσβο

Χρησιμοποίησε αρχικά συντηρητικές ρυθμίσεις για να μη διαρκέσει υπερβολικά:

| Ρύθμιση | Τιμή πρώτης δοκιμής |
|---|---:|
| Αριθμός καμερών | 5 |
| FOV | 180° |
| Βήμα azimuth | 30° |
| Ύψος κάμερας | 10 m |
| Ύψος στόχου/καπνού | 20 m |
| Μέγιστη απόσταση | 4.000 m |
| Απόσταση υποψήφιων θέσεων | 3.000 m |
| Μέγιστοι υποψήφιοι | 150–200 |
| Ελάχιστο υψόμετρο | 0–50 m |

Στο πεδίο **Προαιρετικά: έτοιμα υποψήφια σημεία** άφησε κενό. Το script θα δημιουργήσει μόνο του ένα αραιό grid θέσεων.

## Έξοδοι

Το εργαλείο παράγει:

- **Επιλεγμένες κάμερες**: σημεία με rank και azimuth.
- **Τομείς FOV**: γεωμετρικά πολύγωνα 180° για οπτική παρουσίαση.
- **Μέγιστη ποιότητα κάλυψης**: raster 0–1. Μεγαλύτερη τιμή σημαίνει καλύτερη κάλυψη/μικρότερη απόσταση.
- **Πλήθος καμερών**: raster που δείχνει πόσες επιλεγμένες κάμερες βλέπουν κάθε κελί.
- **Υπολειπόμενος κίνδυνος**: οι περιοχές που παραμένουν ακάλυπτες ή καλύπτονται ασθενώς.
- **CSV αναφορά**: θέσεις, azimuth και ποσοστά κάλυψης.

|---:|---|---:|

Οι τιμές είναι παραδοχές μοντελοποίησης και όχι επίσημος επιστημονικός χάρτης κινδύνου. Μπορούν να αλλάξουν μέσα στο λεξικό `WORLDCOVER_WEIGHTS` του script.

## Πώς να κάνεις καλύτερη τελική αναζήτηση

Η αναζήτηση σε όλο το νησί πρέπει να γίνει σε δύο στάδια:

1. **Χονδρική αναζήτηση:** grid 2–3 km και 150–300 υποψήφια σημεία.
2. **Λεπτομερής αναζήτηση:** δημιούργησε νέο point layer με πυκνότερα σημεία, περίπου ανά 250–500 m, γύρω από τις καλύτερες περιοχές της πρώτης εκτέλεσης. Δώσε αυτό το layer ως έτοιμα υποψήφια σημεία.

Για την τελική αξιολόγηση επανάλαβε τρία σενάρια:

- 2 km: συντηρητικό,
- 4 km: βασικό,
- 6 km: αισιόδοξο.

Μία θέση που παραμένει καλή και στα τρία σενάρια είναι πιο αξιόπιστη.

## Τι δεν προσομοιώνει ακόμη

Το script δεν γνωρίζει:

- νέφη, ομίχλη και ατμοσφαιρική θόλωση,
- πραγματική ευκρίνεια φακού και αριθμό pixels του καπνού,
- δέντρα/κτίρια που δεν αποτυπώνονται σωστά στο DEM,
- κατακόρυφο FOV και tilt,
- δρόμους, ηλεκτροδότηση, τηλεπικοινωνίες και κόστος εγκατάστασης,
- ιστορικές πυρκαγιές ή επίσημο fire-risk map.

Επομένως το αποτέλεσμα είναι εργαλείο σχεδιασμού και όχι τελική απόφαση εγκατάστασης. Οι καλύτερες θέσεις χρειάζονται επιτόπιο έλεγχο.
