ΓΡΗΓΟΡΗ ΕΚΚΙΝΗΣΗ

1. Processing -> Toolbox -> Scripts -> Create New Script from Template.
2. Αντιγραφή του lesvos_fire_camera_optimizer.py στον editor και αποθήκευση.
3. Άνοιγμα: Πυρανίχνευση -> Βελτιστοποίηση θέσεων καμερών πυρανίχνευσης.
4. DEM: το aligned/clipped DEM σε EPSG:32635.
5. WorldCover: το aligned/clipped landcover.
6. Candidates: κενό.
7. Πρώτες τιμές:
   Cameras=5, FOV=180, Azimuth step=30,
   Observer height=10, Target height=20,
   Max distance=4000, Grid spacing=3000,
   Max candidates=150.
8. Επιλογή αρχείων εξόδου και Run.
